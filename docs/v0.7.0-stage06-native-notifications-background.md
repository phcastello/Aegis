## Contrato e segurança

Único comando remoto: `notification.show@1`. Catálogo: `audio.input@1`,
`audio.output@1`, `notification.show@1`. Windows e Android incluem executor nativo;
capability descreve suporte implementado, não concessão automática de permissão.
Android requer permissão de notificações; o pedido é explícito e não se repete
indefinidamente após recusa. A UI informa quando Firebase não está configurado.

`POST /api/nodes/notifications/test`, política autenticada `NodeManagement`, limite
10 pedidos/minuto por Node e corpo HTTP 4 KiB. Request:

```json
{"title":"Aegis","body":"Teste nativo","preferredNodeId":null,"ttlSeconds":60}
```

Título obrigatório até 120 unidades UTF-16 no backend; corpo até 2000. Controles
proibidos, exceto newline/tab no corpo. Limite adicional 2800 bytes UTF-8 no texto
e 3000 bytes no input JSON serializado evita escapar para além do frame de 4096
bytes ou payload FCM. TTL 5–300 segundos, default 60. UUID aleatório `CommandId`,
`ExpiresAt` gerado pelo relógio do backend. Não há HTML, mídia ou ações arbitrárias.

Protocolo v1 estendido de forma compatível: `command` com payload
`commandId/capability/capabilityVersion/expiresAt/input{title,body}`;
`command_result` com `commandId/status`. Envelope mantém
`protocolVersion/type/messageId/sentAt/payload`. Resultados Node permitidos:
`success`, `expired`, `unsupported`, `permission_denied`, `failed`, `duplicate`.
Erros locais não expõem texto arbitrário do OS. Credentials ficam no cofre nativo;
Vue recebe apenas DTOs públicos. Somente a sessão WSS autenticada recebe comandos.

Clientes Stage 05 não anunciam `notification.show` e não recebem este comando.
Não há remote shell, servidor HTTP local, RPC arbitrário, tool LLM ou broadcast.

## Live e resolução

Resolver padrão continua exigindo lease saudável para toda capability, inclusive
áudio. Request interno `Reachability="notification"` aceita background somente
quando todos os requisitos são `notification.show`. Administração/capability/
versão, preferência elegível, prioridade DESC, CreatedAt ASC, Id ASC preservados;
plataforma não participa da seleção. Resolução é snapshot, não garantia de entrega.

Dispatcher revalida administração e lease/capability atual. Online prefere socket
existente. Uma semaphore específica por lease serializa hello ACK, heartbeat ACK,
comando e close; nenhuma espera pelo resultado mantém esse writer bloqueado.
Escrita limitada a 2 s; resultado a 8 s; máximo 16 pedidos pendentes/lease. Cleanup
antigo não remove conexão nova. Resultado velho não confirma comando da nova
lease. Até 16 resultados atrasados/desconhecidos/minuto são tolerados; abuso fecha
a sessão. Command result não renova deadline de heartbeat (25 s / 75 s preservados).

Cliente mantém um único loop socket, até quatro execuções em andamento, resultados
voltando pelo mesmo writer. API OS usa chamada assíncrona cancelável com prazo de 3 s, fora do loop de heartbeat.
No Android, adapter JNI usa oneshot sem panic em callback atrasado e verifica
receiver cancelado antes de chamar OS; não usa callback async upstream que unwrapa
resposta após receiver descartado. Dedupe bounded
256 IDs/10 min; apenas sucesso reserva ID. Expiração live usa hora do hello ACK
mais tempo monotônico, sem confiar no relógio local para availability. Android
compartilha cache persistido bounded entre WSS/FCM e usa CommandId como tag OS.
Não há garantia exactly-once global ou retenção infinita. Não há fila de commands.
Um timeout live não provoca fallback FCM automático: aceitação é ambígua.

uma alteração administrativa não pode ser recolhida; TTL e vínculo local limitam

## Ordem operacional de restart

O restart simultâneo dos containers expôs uma race de DNS na inicialização do
nginx PWA: `host not found in upstream` enquanto a API reiniciava. Após API/DB
voltarem, `docker compose up -d --no-deps aegis-pwa` recuperou o proxy; endpoint
público `/api/health` HTTP 200. Em manutenção, reinicie dependências/API, aguarde
saúde da API e inicie/reinicie a PWA por último. Isso não alterou NPM externo ou
o protocolo WSS, e nenhuma falha temporária foi marcada como sucesso.
