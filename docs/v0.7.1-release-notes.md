# Aegis v0.7.1 — It's Not Stalking. It's a Feature.

*You're terrible at hiding.*

## What's fixed

The full release codename now appears below the Aegis name and running client
version in the open sidebar, including the Android drawer. About shows the same
identity, with the secondary phrase displayed once as a quiet accent.

Android, Windows and the Web Client/PWA use shared editorial metadata for the
0.7 family. The technical version still comes from the installed native runtime
or the web build. A version available for download does not rename the app you
are running. The codename wraps within the existing identity block, keeping the
sidebar toggle accessible.

This patch corrects the presentation omitted from v0.7.0. The
[v0.7.0 feature notes](https://github.com/phcastello/Aegis/blob/v0.7.0/docs/v0.7.0-release-notes.md)
remain the record of the native Nodes, reminders, places and geofencing release.

## Upgrading

Use **Settings → Updates**, or download the official installers from the
[native distribution](https://github.com/phcastello/Aegis/releases/tag/node-v0.7.1):

- [Android ARM64 APK](https://github.com/phcastello/Aegis/releases/download/node-v0.7.1/Aegis-Android-arm64.apk):
  `versionName 0.7.1`, `versionCode 7001999`.
- [Windows x86_64 NSIS installer](https://github.com/phcastello/Aegis/releases/download/node-v0.7.1/Aegis-Windows-x86_64-Setup.exe).

**Install over the existing application; do not uninstall to update.** The patch
keeps the existing package, signing identities and native storage identifiers.
Normal updates preserve Node pairing, credentials, profile and local data. The
historical `node-preview/latest.json` feed remains the update path for existing
installations. About retains its link to Updates; update checks stay in Updates.

The Web Client/PWA receives the same identity through its web build. See the
[verification record](https://github.com/phcastello/Aegis/blob/v0.7.1/docs/v0.7.1-verification.md)
for deployment status and the actual scope of distribution and upgrade checks.

## Known limitations

The Windows microphone investigation and the deferred architectural review of
memory remain separate work. This patch does not establish a verified microphone
fix. Existing platform and geofencing limitations remain documented in the
[v0.7.0 notes](https://github.com/phcastello/Aegis/blob/v0.7.0/docs/v0.7.0-release-notes.md#known-limitations).
No new physical route or owner-device upgrade is claimed by this visual patch.
